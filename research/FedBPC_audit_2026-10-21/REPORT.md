## 1. 结论与证据等级

**当前最值得做的是修复统计定义与建立可信对照，暂不增加新的损失。** FedBPC 的主要问题不是已经证实的“辅助梯度冲突”，而是目标、原型代表的人群、训练场景和评估对象尚未严格对齐。现有记录不能证明 FedBPC 稳定优于 FedAvg，也不能证明它整体思路必然无效。

以下使用三种标签：

- **事实 F**：源代码、数学反例或历史文件直接支持；代码事实不等于实际训练中的主要致因。
- **推断 I**：有证据但存在其他解释。
- **假设 H**：需要指定干预实验，不能作为结果陈述。

| 优先级 | 判断 | 可信度与适用范围 |
|---|---|---|
| P0 | 默认任务是全局均衡、客户端类别缺失的 sharding；不是全局长尾 | F。不能用默认实验支持解决全局长尾的论文主张。 |
| P0 | min_proto_samples=2 可使长尾 IID 的两个尾类永久没有原型 | F：实际 splitter 的合成标签计数复现；不解释旧均衡 sharding 的所有现象。 |
| P0 | 绝对 logit 范数的可靠性不具公共平移不变性 | F：同一预测可跨越拒绝阈值；历史运行的实际影响待测。 |
| P0 | 旧 CSV 缺完整运行配置与代码版本，基线存在任务/预算/预测对象差异 | F。首先限制因果结论与论文比较的可信度。 |
| P1 | minibatch 类均值与全局 macro 目标不一致 | F：一般性数学问题；对原默认“两类各250样本”情形影响可能很小。 |
| P1 | 单贡献者时连续置信权重抵消；单位化丢失集中度 | F。可靠性机制的实际作用弱于直觉描述。 |
| P1 | 不同本地编码器的原型与参数平均后的使用者不一致 | F 为流程；其造成性能瓶颈是 H。 |
| P1 | 稀疏支持、参与缺口及过期机制可能形成尾类引导断续 | I/H。需固定全局计数再干预支持分布。 |
| P2 | 特征范数、温度、类别数共同改变辅助梯度尺度 | F 为几何；是否主要瓶颈是 H。 |

**立即验证排序：A → B → C。论文候选优先考察 B，但必须先通过“精确原型也有用”的否证关卡。** 若 A 修复后 B 无独立收益，应停止把原型维护包装成论文核心。

## 2. FedBPC 实际算法

### 2.1 场景与模型

[默认配置](/Users/ygding/Project/FedClsimb/src/config/fedbpc.json) 为 CIFAR-10、100 客户端、每端 2 个 shard、每轮 10 客户端、200 轮、每轮本地 5 epoch、batch=50、SGD lr=.01、momentum=.9、weight_decay=1e-5、每轮 StepLR .99，训练 seed=2022。

旧 sharding 保存全局全部样本，因此全局训练集均衡。客户端通常只有两种标签，每类约250样本；同类两片也可能形成单类客户端。这里主要是**标签支持缺失**，不应直接称为每个客户端已有类别都呈长尾。独立 longtail 路径才先构造全局长尾，再分配客户端。

[默认 CNN](/Users/ygding/Project/FedClsimb/src/train_tools/models/fedavgnet.py:31) 输出 512 维 ReLU 特征，再接线性分类器。默认没有 BN 或 dropout，不能把其不稳定归咎于 BN。已注册 ResNet 不提供 FedBPC 要求的 get_features，直接换 backbone 会被拒绝；其 BN 设置还需要单独检查。

### 2.2 损失与训练流程

设单位特征 u=f/||f||，有效原型为 p_c，当前 minibatch 出现类别集合为 C_B：

\[
L_{\rm CE}^{\rm present}
=\frac1{|C_B|}\sum_{c\in C_B}\frac1{B_c}\sum_{i:y_i=c}\ell_{\rm CE}(z_i,c).
\]

对有原型的样本，按有效出现类别平均：

\[
L_{\rm align}=E_{\rm present,valid}[1-u_i^\top p_{y_i}],\quad
L_{\rm proto}=E_{\rm present,valid}\left[-\log\frac{e^{u_i^\top p_{y_i}/\tau}}{\sum_{j\in V_t}e^{u_i^\top p_j/\tau}}\right].
\]

总损失为 CE + .1 alignment + .5 prototype CE，τ=.5。[criterion.py](/Users/ygding/Project/FedClsimb/src/algorithms/fedbpc/criterion.py:85) 明确显示：关闭 class_balanced_loss 只改变 CE，两个辅助项仍按类别平均。原型项不直接更新分类器 W；它们通过特征影响骨干。有效原型类别少于2时原型分类项跳过。

[客户端训练](/Users/ygding/Project/FedClsimb/src/algorithms/fedbpc/ClientTrainer.py:35) 后，用同一训练 loader 再遍历一次，模型切 eval，但输入仍是随机增强与随机顺序。对每类先平均单位特征，再单位化：

\[
p_{kc}=\mathrm{normalize}\left(\frac1{n_{kc}}\sum_{i:y_i=c}u_i^{(k,\mathrm{post})}\right).
\]

样本可靠性是

\[
r_i=\operatorname{softmax}(z_i)_{y_i}
\,[1\text{ if correct, else }0.5]\,
e^{-0.05\|z_i\|}.
\]

类可靠性为样本均值；少于2样本或可靠性低于 .05 的整类不上传。它不是按每个样本置信度加权的类特征均值。[提取与可靠性](/Users/ygding/Project/FedClsimb/src/algorithms/fedbpc/ClientTrainer.py:137)。

[服务器原型聚合](/Users/ygding/Project/FedClsimb/src/algorithms/fedbpc/utils.py:8) 使用
\(w_{kc}=r_{kc}n_{kc}/(n_{kc}+5)\)，先加权平均再归一化，然后与历史原型做 EMA。默认旧权重 .5；已有原型的 singleton 更新更慢，旧权重约2/3。新原型直接初始化。age>5 失效，默认至少一个贡献者可更新。

[服务器顺序](/Users/ygding/Project/FedClsimb/src/algorithms/fedbpc/Server.py:88) 是先接收本地训练后原型，再平均模型参数。因此当前原型来自不同编码器，并将被下一轮全局参数初始化的编码器使用。这依赖跨客户端特征坐标、时间版本相容的假设。

默认模型参数仍是样本量 FedAvg。可选头部聚合为**每客户端一个标量权重**，不是逐类分类器行聚合；按 logit 范数和更新范数的鲁棒正偏离惩罚。[分支](/Users/ygding/Project/FedClsimb/src/algorithms/fedbpc/Server.py:319)。当前 JSON 关闭它，而源码缺参数时默认开启，应显式保存完整有效配置。

### 2.3 现有设计的优点及隐含假设

设计简单、原型通信量小，支持有效类掩码、过期、singleton 抑制和多层诊断。其合理动机是防止本地类别频率压制少数类，并用全局类别方向约束表示漂移。

但这些动机依赖：本地类别均衡与测试目标相符；置信度可跨客户端比较；被拒绝的数据主要是噪声；类均值足以表达判别结构；不同本地特征坐标可直接平均；较高原型一致性会改善决策边界。每一项都可能在特定场景失败，不能用模块名称代替验证。

## 3. 已验证的失效机制与反证

### 3.1 局部“均衡”不等于目标风险

若目标是均匀类别测试，经验风险应明确写为

\[
R_{\rm macro}(\theta)=\frac1C\sum_c\frac1{N_c}\sum_{i:y_i=c}\ell_i(\theta).
\]

即使把 minibatch 替换为完整本地数据，样本量加权的本地均衡风险中，第 c 类总质量为

\[
a_c=\sum_k\frac{n_k}{N}\frac{\mathbf1[n_{kc}>0]}{|C_k|},
\]

一般不等于1/C，而且同类不同客户端样本权重也未必相同。多步本地 SGD 与参与者样本量重新归一化进一步使“全局目标”的精确解释复杂化。

轻量反例：两类、稀有先验 .01、有放回 batch=50 时，出现类别平均给稀有类的期望质量约 .1975，目标是 .5；有限总体100个样本、其中1个稀有、无放回抽50时是 .25。公式并非声称实际 loader 有放回，而是在两种明确采样模型中均证伪“每个 batch 类均衡即可全局均衡”。

全局逆先验加权 \(\ell_i/(C\pi_{y_i})\) 的样本均值可表达目标风险；**不能使用 PyTorch 加权 CE 默认的 batch 内权重和归一化后仍声称完全相同**。仓库 FedBTR 的 unreduced weighted mean 已提供可复用做法。多步 FedAvg 仍不是无偏的一次全局梯度估计。

### 3.2 筛选让有数据的类别没有统计量

真实 splitter 在 CIFAR 数量一致的合成标签输入、IF100、100客户端 IID 条件下生成：

- 各类训练量：[1034,2877,371,4800,80,1725,619,133,48,222]。
- 类4、类8分别由80和48个客户端持有，每个持有者只有1个样本。
- min_proto_samples=2 后，这两类的原型贡献者数永远为零。

因此“全球样本稀少”“支持端数量少”“单端样本少”是不同维度。该例全局有48个样本，覆盖48端，却被局部门槛全部抹掉。把 min_contributors 从1升到2不能解决这一问题。

这是配置和机制的确定性冲突；没有在真实图像上训练，所以尚不能量化最终准确率影响。它不适用于旧默认每端500样本的 sharding 归因。

### 3.3 置信度不具有预测不变性，且 singleton 权重抵消

给所有 logits 加同一常数，softmax、预测与 CE 完全不变。对 z=[2,0,-1]，现有可靠性为 .754538；对 z+100，可靠性变成 .000142，低于 .05 门槛。说明所谓可靠性混入了不可由预测解释的公共偏移。

另一方面，只有一个接受的客户端时：
\[
\operatorname{normalize}\left(\frac{w p}{w}\right)=p.
\]
连续置信度与 count shrinkage 不会减小方向更新；实际起作用的是是否通过门槛、以及单独设定的 EMA。默认历史 ver2 平均每轮2.875类由单端更新，约占有更新类别的32%。这不是边缘情形。

对于多个贡献者，n=2 与 n=500、等置信度时权重比约1:3.47，而样本数是1:250。这有可能限制大客户端支配，但也改变全局样本类均值的估计对象。需要明确究竟希望估计哪种总体。

### 3.4 原型接近类中心不等于分类变好

历史 head_false 后20轮，原型与服务端类中心余弦约 .777；文件 proto_false 中约 .861，反而更高。但两者原型间平均余弦约 .145 对 .513，类中心竞争间隔约 .162 对 .051。单纯“同类对齐更好”可能伴随类间分离更差。文件名不能确认消融配置，轨迹也不同，因此这是诊断启示，不能当因果效应。

本地均值的模长本来携带方向集中度信息；先归一化会丢失它。多模态类、客户端域差异与纯采样噪声又会产生相似的低集中度，需要区分。

### 3.5 不能成立的简单归因

**“辅助梯度与 CE 总是冲突”没有日志支持。** head_false 的5次有效观测，余弦约 [.628,.762,.858,.691,.848]，均为正；辅助/CE 梯度范数比由 .98 降到后期约 .24。采样只有一个客户端首批次，不能否认其他类、其他批次有冲突，但足以阻止笼统定案。

**“辅助 loss 大就是压过分类任务”不成立。** 默认 ReLU 使单位特征和原型非负，余弦位于[0,1]。原型 CE 有下界
\[
L_{\rm proto}\ge\log[1+(C-1)e^{-1/\tau}].
\]
τ=.5时，C=10/100/200 的下界约 .797/2.667/3.330。它只是几何下界，未必可达；但已说明损失数值不能直接当梯度强度。当前辅助/CE loss 后期比约1.68，而梯度比约 .24。

**“参数聚合必然毁掉局部成果”与现有平均准确率不符。** head_false 后期本地训练准确率约90%，本地模型在全局测试集约20.6%，聚合模型约50.7%。聚合明显恢复了全局能力。要研究聚合损失，应比较同一批样本上的局部输出集成与参数平均，而不是不同指标的简单差值。

缺失类别的 classifier 行也有有价值的负样本梯度。双客户端、两个类别、特征分别1和2、初始 logits=0，完整平均 CE 行梯度为[.25,-.25]；将客户端缺失类行梯度删除后变成[-.25,-.5]，目标已经改变。因此不推荐未经验证的“缺类行不更新”。

### 4.2 FedBTR 是重要反面与正面证据

已核对20套 experiment/final/CSV，逐类均值与 head/middle/tail 汇总一致。它是项目内部真实已有探索，不能当新提案。完整设计包含全局先验加权、冻结全局骨干的均衡 readout 校准，以及支持相关的输出保留约束。

固定最终轮，在相同 LDA α=.1、IF100 划分上：

| seed | natural CE | balanced only | raw teacher band | full |
|---|---:|---:|---:|---:|
| 2022 | 27.27 | 40.38 | 41.46 | 41.36 |
| 2027 | 未有该配对记录 | 40.71 | 42.29 | 42.29 |

主要可观察提升来自目标重加权；完整 teacher 可靠性机制相对 raw 没有稳定增益。seed2022 重加权也使 head 从58.925降到46.325，说明改善 macro 伴随明确的多数类权衡。IID中 balanced48.69、full49.01、raw49.11；teacher初始化方案45.06，提示“更好的即时 teacher”不保证更好的训练终点。

full 的最差类仍约1.8%/1.4%，均衡目标并未解决所有困难类别。另一划分 seed 的 full 固定终点37.38，而验证选中模型测试43.01，提示轨迹稳定性与选模规则必须预先定义。不能拿最佳验证选模结果与其他方法固定末轮比较。

[现成 transfer diagnostics](/Users/ygding/Project/FedClsimb/src/algorithms/fedbtr/diagnostics.py:248) 能追踪“全局错误、teacher正确”的固定验证样本群、真实批次重放、局部输出集成和聚合模型。历史20份CSV均没有 transfer/字段，因此关键机制尚未被这些记录验证。应复用它，避免重复开发蒸馏模块。

### 4.3 必须修正的比较口径

| 项目 | 当前差异 | 处理 |
|---|---|---|
| 数据划分 | 当前 FedNH JSON 为 LDA .1，多数默认为 sharding2；旧 LDA 最少样本修复与 longtail LDA 规则不同 | 共享同一 split manifest 与指纹，禁止仅写“α=.1”就视为相同。 |

| 实现 | FedSC 上游兼容路径部分正则可能因异常回退为零 | 先验证真实非零梯度，不拿失效实现当强基线。 |
| 时间 | BaseServer 的 round time 未含后续 FedBPC诊断；各法评估频率不同 | 同步设备后分阶段计时，单列诊断成本。 |
| 评价 | 均衡CIFAR测试下 overall=macro recall；本地test用全局test | 不宣称两个数相等是双重证据；客户端泛化须独立本地测试集。 |

种子也不充分：[BaseServer sampling](/Users/ygding/Project/FedClsimb/src/algorithms/BaseServer.py:110) 每轮按 round_idx 重设 NumPy 随机数，train seed 不改变参与序列。额外原型遍历消耗训练随机性，长尾 DataLoader 自带 generator 又不在 FedBPC 全局 RNG 保存范围内。同 seed 未必意味着同增强批次；短分支实验要验证输入哈希一致。

## 5. 因果链与八个可证伪假设

数据决定样本数、类支持、域和难度；它们改变本地可见风险与采样方差。局部训练改变表示和边界，统计提取再过滤、单位化和跨时间混合；参数聚合改变使用统计量的模型。验证性能是这条链共同结果。以下各项不能从总体准确率单独识别。

| 假设 | 为什么值得研究／已有证据 | 最低成本证伪与反例 | 成立后的方向 |
|---|---|---|---|
| H1 主要增益缺口来自目标不一致 | 类均值不等于 macro；BTR balanced 已带来大部分改善 | 同一冻结特征/同一全局模型，比较完整 macro 梯度、现有本地均衡梯度、全局权重梯度。若默认 sharding 三者近似一致，则不是默认旧实验主因 | A 的显式目标；不主张新算法 |
| H2 可靠性筛选系统性丢失有用尾类信息 | min2 确定性拒绝；公共平移反例 | 固定模型，把同一已提取特征的 gate前后类质量、干净验证误差比较；加入少量标注噪声。若 gate 对罕见类确实提高估计与预测，不能一概删除 | A计数门槛修复；B保留统计量质量 |
| H3 原型误差主要来自编码器/时间不一致 | postlocal→平均模型使用；额外随机视图 | 同一轮同一数据，global-pre、local-post、global-post三种提取；对精确当前全局类矩比较误差。若共同编码器不减误差或误差不影响验证，停止此解释 | B共同版本统计；与RUCR强对照 |
| H4 参与方差比原型均值偏差更关键 | 支持稀疏；singleton约三成；age机制 | 固定全局计数和模型，穷举/重采样参与子集，测 perclass MSE、零贡献间隔；全参与仍同样差则推翻采样主因 | B残差修正，或C采样 |
| H5 单均值原型本身不足以表达尾类 | 类中心余弦与竞争间隔可反向变化 | 冻结模型，用全训练数据精确NCM与均衡线性探针、每类多中心诊断。若精确均值仍弱且加原型项无梯度收益，修原型统计不是正确路线 | 放弃B；转向表示或边界，不立刻叠多原型 |
| H6 某些类的梯度冲突被全批次平均掩盖 | 当前总体余弦正但样本极稀疏 | 固定检查点按类计算CE/aux梯度、范数与一步验证变化，head/backbone分开。若多数困难类仍正对齐且无负迁移，否定冲突叙事 | 只有成立才讨论逐类调节 |
| H7 校准修正无法跨局部输入支持与聚合保留 | BTR完整组件无稳定增量，已有诊断未运行 | 同批次重放跟踪固定验证 cohort；分别比较教师、局部、输出集成、参数平均。若teacher自身改错或local已消失，聚合不是首因 | 选择确切失效环节再改机制 |
| H8 难度/域覆盖而非频率决定最差类 | BTR最差类非必然最稀有；类先验校正仍残留低召回 | 固定计数交换类别身份，按类混淆与冻结特征探针；同时控制训练样本量。若失败随频率迁移而非语义迁移，则主要是供给 | 难度驱动研究；必须对照FedIIC/FedYoYo等 |

对 H3、H5 的反方尤其重要：所有客户端从同一模型出发，坐标未必严重错位；单均值即使估计正确也可能无法区分多模态分布。不能为了保留 FedBPC 强行继续。

## 6. 三条有实质区别的方案

### A：保留框架，修正可解释性与统计门槛

**问题：** 当前门槛与目标定义会在明确场景自相矛盾。A是工程与目标对齐方案，创新性低，优先级最高。

步骤：

1. 独立确定性 calibration loader 提取原型，隔离训练 RNG；保存完整配置和抽样/批次指纹。
2. CE 可选 global_macro：逐样本乘 \(1/(C\pi_c)\)，再作样本均值；原 present_class 模式完整保留。预先选择 macro 或自然分布目标。
3. 第一单因素实验令 gamma_logit_norm=0；后续若保留范数项，使用 centered logits \(z-\bar z\)，单独比较。中心化只修不变性，不证明置信度校准可靠。
4. min_proto_samples 允许1，上传 count 与原始均值模长；比较硬门槛和全纳入。先使用统一 FedAvg 头部，避免额外自由度。
5. 若需小样本收缩，用方向合成以外的显式步长，例如
\[
p_c^{t+1}=\mathrm{normalize}[(1-\eta_c)p_c^t+\eta_c\hat p_c],\quad
\eta_c=\eta_0 \frac{M_c}{M_c+s},
\]
其中 \(M_c=\sum_{k\in S}n_{kc}\)，s是预先固定的计数尺度；新类无旧原型时直接初始化并记录低支持，不伪造可靠度。该公式只是可理解的收缩，不能称置信区间。

A的低风险指开发与可解释性，不代表性能必然上升。全局重加权可能提高尾类同时降低头类、放大噪声；允许singleton可能引入坏方向；固定增强也可能降低统计对训练视图的代表性。默认全局均衡 sharding 中 A的目标改动可能几乎无收益。

成本：相对原BPC仍约每轮额外一遍参与端前向，原型O(mCD)通信，计数O(mC)，实现低。不要把上述五项一次性合并跑后宣称每一项有效；先单因素、后最小组合。

最小验证：已有轻量反例 + 两个固定检查点的 gate/梯度重放；再进入短训练。没有新颖性承诺，也不应单独作为高水平方法论文。

### B：以确定的全局类别矩为目标，维护可核验的原型估计

**问题：** 原方案对不同模型下、经选择且单位化的局部方向做平均，目标不明确。B重新设计原型统计，而非增加新loss。

定义：固定当前广播编码器 \(f_{\theta_t}\)、固定预处理，局部保留未再次单位化的单位特征均值
\[
m_{kc}^t=\frac1{n_{kc}}\sum_{i\in D_{kc}}\frac{f_{\theta_t}(x_i)}{\|f_{\theta_t}(x_i)\|},\qquad
m_c^t=\sum_k a_{kc}m_{kc}^t,\quad a_{kc}=n_{kc}/N_c.
\]
n=0 项为零。全局类别计数必须已知或有独立估计，不从当前参与端重新归一化。

**B0先行：** 所有参与端在本地训练前用同一广播模型抽取统计量；服务端用
\[
\hat m_c^{HT}=\sum_{k\in S_t}\frac{a_{kc}}{q_k}m_{kc}^t
\]
估计当前矩。q_k 是真实包含概率。该未归一化向量对参与采样无偏，但小q时方差大，可能零向量；只有其模长充分非零才转为方向。单位化后的方向不再保证无偏。全参与版本应与集中式流式类均值数值一致。

**B1仅在B0有用后尝试：** 保存上次局部矩 h_kc，在抽样前固定；用可预测历史残差
\[
\hat m_c^{CV}
=\beta\sum_k a_{kc}h_{kc}
+\sum_{k\in S_t}\frac{a_{kc}}{q_k}(m_{kc}^t-\beta h_{kc}).
\]
β=0回到B0，β=1为直接历史修正。条件于当前模型与抽样前历史，其期望仍是 \(m_c^t\)。历史来自旧编码器不破坏这个代数结论，但会使残差方差变大。**不能据此宣称陈旧模型下的表示已被精确传输。**

采样前决定β，避免根据同一抽样结果任意调β后仍套用无偏性。首版仅比较β=0/1；若需要自适应，以独立历史区间估计，明确它是可预测控制量。先用旧h计算残差与当前估计，再更新参与客户端的h；不能提前覆盖缓存。保留矩误差、模长、age、支持和方向误差；不要先做置信度剔除再声称估计全体样本。

另一个失效边界是：CV含有带符号残差，估计可能出现负坐标或模长超过1，即便真实ReLU单位特征均值始终非负且位于单位球内。单位化可能放大这些异常。若投影回非负单位球，必须承认引入有限样本偏差并单独消融；首版先记录越界率，不能忽略它。

算法时序：广播模型 → 参与端提取 → 服务器估计并回传当前原型 → 本地训练 → 参数聚合。这样当前轮引导使用同一初始编码器坐标，代价是增加一次同步；本地训练过程中编码器仍变化，并未完全消除漂移。和原始单轮流程比较时必须计入延迟。

理论上改善的是**指定矩的估计偏差/方差**，并不自动改善泛化。已完成的4客户端枚举：原始估计方差1，预测性历史修正后 .0625；反预测历史变成3.0625。该反例明确说明历史缓存可能更差，是现有控制变量原理的演示，不是新定理或实验性能。

预期作用：稀疏/不均支持类免于门槛归零，低参与率下历史有预测性时受益；共同编码器有利于减少跨端坐标差异。头类也可能受益，但如果类内多峰，精确均值仍无判别价值。强域异质性、快速漂移、少数类标签噪声和极小q会使方案失败。

成本：一遍前向与原BPC类似，但时序前移并多同步；上传O(mCD)，服务端内存最坏O(KCD)，可稀疏存非空类，另存计数和时间。K=100,C=10,D=512的float32全表约2.05MB；C=100时约20.48MB；不含框架开销。保留历史统计具有与原型相同的隐私讨论，不声称正式隐私保护。

**创新边界：** [RUCR](https://doi.org/10.1109/TIFS.2024.3402361) 已用全局编码器；[FedVARP](https://arxiv.org/abs/2207.14130) 已用历史残差。直接组合是变体，尚不足以成为贡献。值得验证的研究命题是：类别支持稀疏使“筛选后方向”产生可测总体偏差，而明确目标矩的估计方法能在统一预算下稳定改变决策；需要给出适用与失效边界，并击败B0、RUCR式共同编码器以及简单A。

最小验证：冻结模型全客户端真实矩作为诊断参照，枚举/重采样参与集合比较原BPC/B0/B1，随后只做一步原型引导对验证风险的影响。若估计显著改善却预测与梯度收益均不变，B不进入完整训练。

### C：跳出原型框架，主动分配类别梯度的观测机会

**问题：** 如果稀有类别主要因长期未被有效观测，改善已有原型可能治标。C去掉原型辅助项，从客户端参与机制干预供给。

为避免把多步漂移与抽样无偏性混在一起，最小版本使用共同参数点上的联邦梯度步骤。定义
\[
a_{kc}(\theta)=\frac1{N_c}\sum_{i\in D_{kc}}\nabla_\theta\ell_i,\quad
G_c=\sum_k a_{kc},\quad \nabla R_{\rm macro}=\frac1C\sum_cG_c.
\]
梯度按真实类别分组，仍保留对全部 classifier 行的正负梯度；不做缺类行屏蔽。

在独立 Bernoulli 参与下，客户端包含概率q_k，预算为期望参与数m：
\[
\hat G_c=\sum_{k\in S}\frac{a_{kc}}{q_k},\qquad
V_c=\sum_k\frac{1-q_k}{q_k}\|a_{kc}\|^2.
\]
这里 \(V_c=E\|\hat G_c-G_c\|^2\) 对固定梯度和独立采样成立，不涵盖 minibatch 内噪声、通信丢失或多步局部漂移。

用抽样前可获得的预测值v_kc求
\[
\min_{\mathbf q}\max_c\sum_k\frac{1-q_k}{q_k}v_{kc}
\quad\text{s.t.}\quad
q_{\min}\le q_k\le1,\quad \sum_kq_k=m.
\]
固定非负v时这是凸的极小极大方差代理问题，不是直接优化 worst-class accuracy。初版v可取 \((n_{kc}/N_c)^2\) 的计数代理，明确它不是实际梯度范数；只有计数代理有效后才考虑历史范数，避免先让所有候选客户端计算昂贵梯度。

步骤：收集训练类计数 → 确定q → 独立采样 → 共同θ上计算一次完整本地梯度/指定无偏batch梯度 → HT上传聚合 → 一次服务端SGD更新。最小版本不加动量。使用固定分母与真实q，不用随机参与者权重和重新归一化。空参与轮应记作无更新并计入通信时间，不能随意重抽后沿用原q。

独立采样的参与数有波动，应与相同期望及实际累计预算的均匀Bernoulli对照。若必须固定恰好m端，需换成有已知一阶/二阶包含概率的抽样设计并重新计算协方差，不能照搬上面的独立方差公式。把这项方法直接套到E=5的FedAvg更新，仅是启发式扩展，不继承共同点梯度结论。

已完成4端两类枚举：前三端共同支持类0、第四端独有类1，期望2端时，均匀q=.5两类方差为(.333,1)；q=(.4,.4,.4,.8)为(.5,.25)，最差方差从1到 .5。它同时牺牲类0的方差，展示真实权衡，不能解释为准确率收益。

成本：不传原型；最简单版一次上传完整模型梯度，O(mP)，计数存储O(KC)。完整本地梯度一遍前反向，但每次更新需要通信，可能比E=5严重增加达到目标精度所需轮数。算法实现中高复杂度，延迟/可用性强约束会破坏理论预算。

预期尾类更常被观测，但高噪声稀有端可能被过采样，多数类更新机会减少；域差异/梯度冲突不会自动解决。若支持已经均匀、客户端都可见所有类，收益很可能很小。

**创新边界：** [Optimal Client Sampling](https://wenlin-chen.github.io/publication/chen2022optimal/) 已研究最优采样；[Fed-CBS，ICML2023](https://proceedings.mlr.press/v202/zhang23y.html) 已直接通过类别均衡选择客户端；[SSDI](https://proceedings.mlr.press/v300/zeng26b.html) 已区分偏斜与缺失。因此“让尾类更常参与”本身没有新颖性。候选区别只能落在固定macro目标下的HT估计、类别条件方差的极小极大分配与实际资源权衡，须与Fed-CBS及范数采样逐项比较；若只有计数覆盖改善，不足以构成新贡献。C目前是高风险研究备选。

## 7. 方案排序与反方审查

| 维度 | A | B | C |
|---|---|---|---|
| 理论合理性 | 高：修复不变性、定义目标 | 高：矩估计身份明确；泛化联系未证 | 中高：抽样估计清晰；方差代理不等于准确率 |
| 直接证据 | 有确定性反例及BTR支持 | 有统计失真代码证据，缺训练因果证据 | 只有支持机制和玩具验证 |
| 性能潜力 | 修复明显失效场景；旧sharding可能有限 | 条件于原型本身有用 | 条件于参与供给是瓶颈 |
| 新颖性 | 低 | 中、待排除近邻，不是已成立贡献 | 中、采样领域近邻多 |
| 实现/验证成本 | 低 | 中 | 高 |
| 最大风险 | 修复虽正确却不涨分 | 估计更准而表示/边界无改善 | 更小方差却更慢、稀有噪声放大 |
| 当前推荐 | 立即做 | 通过oracle关卡后优先研究 | 只有H4强且B不足才投入 |

A优先，是因为它能低成本排除错误前提。B优于C作为当前论文候选，是因为它紧贴现有可审计统计失真，能用固定模型与同一数据做强反事实，且无需先重构整个优化过程。这个排序不是对最终效果的承诺。

## 8. 论文定位与停止条件

可暂定研究问题：**在部分参与、类别支持不均的联邦学习中，可靠性筛选和局部方向归一化如何改变原型估计对象，这种改变何时真正影响全局分类？**

潜在贡献必须满足三个条件：

1. 用严格反例和控制实验分离目标偏差、估计方差与表示能力不足；修复基线后现象仍然存在。
2. 方法只针对被验证的瓶颈，数学结论准确限定于未归一化矩/共同参数点；不把无偏估计升级成泛化保证。
3. 在匹配数据、模型、目标和资源后，超越简单全局重加权、共同编码器、均匀参与与相关原型方法；报告失败区域和头尾权衡。

可以形成机制分析论文，也可能最终只是证明该路线不值得继续。若全量精确原型无帮助，停止B；若A已经解释全部收益，不宣称B有独立贡献；若C仅提高观测率而预算效率更差，不作为性能方法。现阶段没有SOTA声明，也没有未验证的提升幅度承诺。
