# 局部类别不平衡：分布原型补全方案

日期：2026-10-22。代码名：FedBPC-Complete / fedbpc_complete。状态：**可运行研究候选，尚未证明在真实图像任务上稳定超过原 FedBPC。**

## 1. 本轮目标与结论

只研究全局类别大致均衡、客户端经 sharding / LDA 划分后出现的本地类别比例偏斜与缺类。无需全局长尾假设，也不以论文级新颖性为目标。原 FedBPC 保持完整，用于对照；新算法独立实现。

本轮完成了实现、性质测试、真实 PyTorch CPU 集成测试以及多组配对合成实验。结果支持“原型补全能缓解某些严重 LDA 设置中的失衡”，但**不支持“全部新增模块都已经证明必要”或“已经全面优于现有方法”**。分片设置的小幅退化、对齐与梯度路由的不一致收益均保留在记录中。另一个固定梯度修正方案出现严重退化，已从正式代码删除并归档。

设计的重点是三个相互约束的问题：补多少类别信息、如何表示这部分信息、允许它修改模型的哪一部分。方差、原型时效和梯度路由均由这些问题引出；其性能价值仍要通过消融决定。

## 2. 从局部训练的梯度出发

设编码器产生 z=fθ(x)，普通线性分类器为 h(z)=Wz+b。客户端 k 的类别先验是 πkc=nkc/nk，全局训练先验是 pc=Σk nkc/Σk nk。标签偏斜情况下，即便各客户端的类条件分布近似相同，局部目标仍是：

$$R_k=\sum_c\pi_{kc}\,\mathbb E[\ell(h(f_\theta(x)),c)\mid y=c].$$

在一个类别 c 缺失的客户端，softmax 分类器仍通过其他类别样本得到该类别的负向梯度，却没有相应的正类观测。一次小步更新再准确聚合时，其他客户端可能补偿它；多个局部步、动量、部分参与和表征非线性会使这种补偿不再精确。因此，**局部先验不同并不自动意味着 FedAvg 有问题**；要诊断的是局部训练累积后的偏移。

对局部缺类使用更大的样本权重没有作用，因为根本没有对应样本。仅让现有类别特征靠近中心，也不能给缺失类别的分类头补上正类证据。共享原型有用的角色，是提供客户端没有看到的类条件特征信息。

但均值并不是分布。对固定线性头，CE 对特征是凸函数，通常有：

$$\ell(h(\mathbb E z),c)\leq\mathbb E\ell(h(z),c).$$

只在均值上分类正确，不能保证边界覆盖真实类内变化。这是引入第二阶统计的直接理由，不是因为“复杂模块更多”。

## 3. 机制一：在同一个特征坐标系里计算分布原型

每轮先广播全局模型。参与客户端在**本地训练集**上，以此轮尚未更新的全局编码器计算：

$$n_{kc},\quad s_{kc}=\sum_{i:y_i=c}z_i,\quad q_{kc}=\sum_{i:y_i=c}z_i\odot z_i.$$

服务器合并当前参与者的原始统计：

$$N_c=\sum_k n_{kc},\quad
\mu_c=\frac{\sum_k s_{kc}}{N_c},\quad
v_c=\frac{\sum_k q_{kc}-(\sum_k s_{kc})^{\odot2}/N_c}{N_c-1}.$$

N>1 时 v 是对角样本方差；N=1 时仍保留均值、将不可估计的方差置零，日志记录 support=1。**零方差在这里不表示总体没有变化。**

这保留了客户端之间均值差异带来的类内方差。直接平均各客户端方差会漏掉这一项，例如两个客户端各只有一个样本 -1 与 +1，其各自方差都无法估计，但合并样本方差为 2。

具体约束：

- 特征不做单位归一化，保留与普通线性分类头一致的尺度。
- 所有当前统计使用相同 encoder_version；版本不同立即报错。
- 当前有观测的类别直接刷新，不把不同编码器版本的均值做 EMA。
- 当前没有观测的类别可短期缓存；可靠系数 r=valid/(1+age)，超过 5 轮失效。年龄折扣是保守启发式，不能解释为校准过的正确概率。
- 零均值也是合法分布原型；仅方向对齐跳过无定义的零方向。
- 提取统计使用训练图像及确定性的评估变换；不读取测试图像或测试标签来生成原型。提取过程保存恢复 RNG，不消费训练采样流。
- 原始矩以 float64 累计并传输，合并后均值和方差为 float32；避免原始二阶矩相减时过早丢失精度。

必须先收集参与者统计、合并广播原型，再启动本地训练，因此每轮有两阶段同步。缓存原型仍会过时；同版本要求只保证当前刷新部分的坐标一致。

## 4. 机制二：守恒地补充分类头的类别质量

定义客户端相对全局先验的不足量与过量：

$$d_{kc}=(p_c-\pi_{kc})_+,\quad e_{kc}=(\pi_{kc}-p_c)_+,\quad D_k=\sum_c e_{kc}.$$

原型补充的权重为：

$$a_{kc}=\alpha r_c d_{kc},\qquad A_k=\sum_c a_{kc}.$$

对存在的真实类别定义：

$$b_{kc}=1-\frac{A_k}{D_k}\frac{e_{kc}}{\pi_{kc}}.$$

D≈0 时 b=1、a=0；不存在的真实类别无需计算除法。α∈[0,1]，默认 0.5。由此得到：

$$\sum_c\pi_{kc}b_{kc}+\sum_c a_{kc}=1.$$

完整新鲜覆盖时，分类头的类别质量为：

$$\pi_{kc}b_{kc}+a_{kc}=(1-\alpha)\pi_{kc}+\alpha p_c.$$

有类别原型不可用时，只补可用部分，真实样本扣减也同步缩小；不会“先降低真实学习权重却没补进对应信息”。α=0 或全部原型不可用时回到原始 CE。

这只是**分类头目标中的类别系数守恒**，不等于真实全局风险已被精确重建。当前参与者的类条件分布、原型近似和缓存年龄仍可能产生误差。

权重按完整本地数据计数计算，不能在每个 minibatch 中重新归一化；否则单类 batch 中所有权重相同，会被归一化直接消掉。

## 5. 机制三：让分类边界考虑原型周围的变化

将缺少的类条件特征近似为 N(μc, γ diag(vc))。对原型目标类 c、竞争类别 j，定义：

$$\tilde h_{cj}=w_j^\top\mu_c+b_j+
\frac{\gamma}{2}\sum_d v_{cd}(w_{jd}-w_{cd})^2.$$

原型风险使用：

$$U_c=\operatorname{CE}(\tilde h_c,c),\qquad L_{\rm replay}=\sum_c a_{kc}U_c.$$

类内变化越大、当前两类权重在该方向上的差异越大，竞争 logit 的修正越大。这迫使分类头避免只在均值点获得高置信、却把同类变化轻易划到另一侧。

在指定高斯假设成立时，U 是期望 CE 的 Jensen 上界；**不是任意真实特征分布上的保证，也不是精确的期望风险**。对角近似丢失相关性，上界可能松，γ=1 也未经过真实数据调参。γ=0 精确退化为均值原型回放，是必须保留的消融。

该数学工具沿用 [ISDA, NeurIPS 2019](https://proceedings.neurips.cc/paper_files/paper/2019/file/15f99f2165aa8c86c9dface16fefd281-Paper.pdf) 的高斯扰动期望 CE 上界原理。本方案把中心换成联邦共享类均值，并用于本地类别不足部分；不把公式本身当作新理论。

实现使用矩阵乘法计算二次型，不创建 C×C×D 中间张量，也不显式采样伪特征。所有原型统计都 detach，回放只更新线性头。

## 6. 机制四：分类头补全，骨干继续学习全部真实数据

一个容易忽略的问题：如果直接使用 b_y CE，再加只训练头的原型项，骨干对真实数据的梯度也被降低了；原型并不会补回这部分图像表征学习。

当前版本用 stop-gradient 路由区分两个目标。记 sg 为停止梯度：

$$L_{\rm real}=\frac1B\sum_i
\left[\ell(h(z_i),y_i)+(b_{ky_i}-1)\ell(h(\operatorname{sg}(z_i)),y_i)\right].$$

其前向数值等于加权真实 CE，但梯度为：

$$\nabla_\theta L_{\rm real}=\nabla_\theta L_{\rm natural},\qquad
\nabla_W L_{\rm real}=\frac1B\sum_i b_{ky_i}\nabla_W\ell(h(z_i),y_i).$$

再加回放项与可选方向约束：

$$L=L_{\rm real}+L_{\rm replay}+\lambda L_{\rm align},$$

$$L_{\rm align}=\frac1B\sum_i
\frac{n_k}{|\mathcal C_k|n_{ky_i}}\,r_{y_i}
\left(1-\cos(z_i,\mu_{y_i})\right).$$

方向约束仅作用在本地存在、有有效非零方向原型的类别。分母始终是原始 batch 大小，不按筛选后数量重新归一化。其作用假设是减小局部特征坐标漂移；它也可能压缩有用的类内结构，所以 λ=0 必须作为对照。

严格说，这是带停止梯度的多目标更新规则，不是普通共享标量经验风险的标准全梯度。保留骨干梯度并不意味着骨干每一步都与 FedAvg 相同：随着分类头改变，后续自然 CE 梯度也会改变。

实现保留 preserve_backbone_gradients=False 的耦合版本。实验显示该路由在一组设置有益、另一组没有胜过耦合版本，因此目前是结构合理的默认假设，尚非经过普遍验证的必需机制。

## 7. 一轮完整流程

1. 按仓库原规则抽客户端，保存参与记录；客户端从同一个全局模型出发。
2. 各参与客户端提取训练集的类计数、一阶矩和对角二阶矩。
3. 服务器刷新分布原型、更新缓存年龄，再广播原型库。
4. 客户端计算固定类别质量 a、b；第一轮 warmup 只用自然 CE。
5. 本地训练：自然真实数据梯度训练骨干；质量校正和分布原型回放训练头；可选方向约束。
6. 上传模型，按原始客户端样本数执行 FedAvg 聚合，不改为类感知头聚合。
7. 用普通全局分类头评估；不使用测试时原型集成、额外分类器或测试集调权。

| [CCVR, NeurIPS 2021](https://arxiv.org/abs/2106.05001) | 用近似高斯混合模型采样虚拟表征，在联邦训练后校准分类头 | 本方案在每轮本地优化中按客户端不足质量补充头目标；额外同步成本更高，未证明优于训练后校准 |

| 原仓库 FedBPC | 本地训练后生成置信加权方向原型，配合原型约束和类别平衡 CE | 新实现改变统计时序、表示尺度、类别质量分配及头/骨干梯度关系，不继承旧模块作为设计约束 |

不做“首次提出联邦高斯原型”的声明。本方法是已有数学工具围绕具体优化问题的工程组合，是否值得保留由性能、稳定性和成本决定。

## 9. 可证伪假设及当前证据

| 假设 | 最小验证 | 当前结论 |
|---|---|---|
| H1 缺类头需要正类更新 | 单批次梯度检查，观察缺类头行 | 已验证回放给出缺类正类梯度；尚不等于提升泛化 |
| H2 均值不足以描述边界风险 | 同均值不同方差 + 高斯数值积分；γ=0 消融 | 已验证理论反例；多组 LDA 中完整分布版本优于均值版，但分片收益不一致 |
| H3 不同本地编码器混合会污染统计 | 同编码器分布统计与集中统计逐项比较 | 同编码器聚合的实现等价性已验证；更高同步成本是否值得仍需真实实验 |
| H4 质量守恒避免回放随缺类数量任意放大 | 不同先验、缓存缺失、单类 batch 的守恒测试 | 已验证代数与实现；α=0.5 的最优性未验证 |
| H5 骨干不应被只补头的机制同时降权 | 梯度路由检查 + coupled_backbone 消融 | 梯度性质成立；跨划分性能证据混合 |
| H6 对齐能保护共享原型坐标 | λ=0 对照及真实特征漂移诊断 | 合成消融收益混合，不能称为已证实必要 |
| H7 原型梯度固定修正足以替代回放 | 固定原型头梯度修正分支 | 当前实现明显失败，已拒绝并移除 |

## 10. 已运行实验的解释

详见 [RESULTS.md](RESULTS.md) 和各 synthetic 子目录的逐轮原始 JSON。数据全局均衡，四类、八客户端，只改变本地 sharding / LDA。

当前方法在三组不同合成数据/划分中的 LDA 最终 Top-1 均值为 94.82%、92.81%、93.07%；FedAvg 对应 92.45%、62.57%、84.28%。这些差异说明严重标签偏斜下存在收益潜力，不能外推为真实图像任务收益。部分种子新方案下降，原 FedBPC 在第二组最终指标更强，分片设置新方案整体没有优势。

固定梯度修正分支在两组 LDA 的最终均值分别只有 37.92% 和 26.14%，停止推进。可能原因包括类条件近似误差、固定修正重复作用，以及带负系数的方差上界差值形成反向正则；这些是待拆解的解释，实验只证实该分支不可靠。

**推荐排序：**

1. 先用同一真实划分比较 FedAvg、原 FedBPC、完整候选和均值消融。完整候选是待检验方案，不直接替换原方法。
2. 若只需最保守的落地选择，现有证据不足以建议全面替换原 FedBPC。
3. 多中心原型仅在真实特征证实单高斯丢失关键多模态结构后再考虑，不在当前版本中堆叠。

## 11. 开销与适用限制

每个参与客户端每轮额外完整前向遍历一次训练集。E=5 时额外样本访问量是原训练的 1/5，但这是无反传前向，不能直接换算为 20% 墙钟时间。另有一次原型同步。

对 C 类、D 维，上传原始矩和计数约 16CD+8C 字节；下载当前实现的 bank/prior 约 8CD+21C 字节。C=10、D=512 时，合计约 123,170 字节/客户端/轮，不含模型、通信封包与元数据；首次另有全体客户端计数。实际日志按 Tensor 大小记账，统计满 C 的稠密载荷，未假装稀疏压缩。

存储约 O(CD)，回放计算约 O(MCD)，M 为本客户端有补充质量的类别数；不生成 C×C×D 张量。类数很大时仍需评估矩阵计算成本。

限制包括：早期随机表征、单例无法估计方差、对角高斯近似、统计变换与训练增强不完全一致、缓存编码器漂移、同标签的客户端条件分布不同、类内多模态被均值对齐压缩、极大局部步数。该方案不能在无真实缺类图像时直接训练缺类的骨干特征。

首版要求 get_features=True、普通 nn.Linear 分类头；拒绝含 BatchNorm 的模型，避免忽略客户端缓冲状态语义。默认 FedAvg CIFAR 网络已通过接口与矩提取测试。没有新增差分隐私或安全聚合保证。

## 12. 真实数据验证与停止条件

保持全局 CIFAR-10 原始训练分布；K=100、q=0.1、E=5、batch=50、SGD lr=.01/momentum=.9/weight_decay=1e-5，StepLR gamma=.99。sharding=2 与 LDA alpha=.1，固定 partition_seed=19940817、共享缓存和客户端参与序列。

先在训练机 profile 3 轮，再预算 30 轮筛查。最小筛查为 FedAvg、原 FedBPC、完整候选、均值消融 × 两划分 × 一个 seed，共 8 runs；每 run 期望约 750,000 次 SGD 样本访问，候选另约 150,000 次统计前向。LDA 每轮实际量随被选客户端大小变化。此预算**尚未执行，也未授权为自动任务**。

筛查通过后才做 200 轮、三训练 seed；最后追加独立 partition seed。不要把同划分的三个初始化当作三个独立异质性设置。完整评估优先预算核心方法，再选对齐、耦合梯度及 α 消融，不一次扫大矩阵。

评估最终 Top-1、末 10 轮均值与波动、Macro-F1、各类 Recall、Balanced Accuracy、最差类、缺类/少数类客户端的训练后遗忘、时间与通信；全局均衡时不使用全局 head/medium/tail 分组解释结果。仓库日志已提供逐类 Recall，可计算 Balanced Accuracy 和最差类。

对齐、方差、路由必须逐一证明贡献；若某模块只增加开销且不同 seed 下无稳定收益，删除或默认关闭。若完整方案在相同预算下仍不优于原 FedBPC，不以继续堆模块作为默认下一步，应检查原型代理风险与真实类别条件梯度的偏差。

本机已有 CPU PyTorch，但尚未定位到可用 CIFAR 数据和 CUDA/MPS。未下载数据、未运行完整 CIFAR 训练。执行入口、配置及恢复说明见 [README.md](../../src/algorithms/fedbpc_complete/README.md) 与 [RESUME.md](RESUME.md)。
